# Thème visuel du tableau de bord

Le tableau de bord utilise un thème sombre, pensé pour faire ressortir les courbes et les chiffres clés.

## Palette

| Élément | Couleur | Code hex |
|---|---|---|
| Fond de page et des cartes | Bleu nuit | `#090F3D` |
| Fond des segments | Bleu nuit foncé | `#0A0D4C` |
| Chiffres des cartes KPI | Blanc | `#FFFFFF` |
| Titres des graphiques et libellés | Blanc | `#FFFFFF` |
| Courbes et barres de données | Bleu vif | `#1B92F7` |

Les valeurs ont été relevées à l'écran sur des captures du tableau de bord. Elles peuvent différer de quelques unités selon le réglage de l'écran.

## Pourquoi ce choix

- **Contraste** : le blanc sur bleu nuit reste lisible, y compris pour les chiffres des cartes.
- **Mise en valeur des données** : le bleu vif ne sert qu'aux données. Le reste de l'interface reste neutre.
- **Lecture prolongée** : un fond sombre fatigue moins les yeux lors d'une présentation.

## Pour reproduire ce thème

Dans Power BI : **Affichage > Thèmes > Personnaliser le thème**, puis renseignez la couleur de fond et la couleur du texte principal avec les codes ci-dessus.
